# Findings in need of being adressed (bugs, improvements, etc.)

- There needs to be a configuration screen
- The dkb menu needs to have the configuration menu added to take you to the configuration screen with cmd-, as a shortcut
- Markdown editor needs to allow vi-mode, configurable in the configuration menu
- There needs to be a light/dark mode toggle (light, dark, follow system).
- It should be possible to configure line numbers in the editor window (set in the configuration screen)
- Backlog, Active, Done should be displayed as tabs, not buttons
- It needs to be possible to create an absolute sort of items in each column (Yesterday, Today, This Week, Next Week). That sort should carry over per column.
- The icon when running needs to be something other than a black box with exec (like termianl window)
- The application needs to be packaged like a normal Mac App
- Publish to the Mac App store
- The configuration needs to allow overriding the default storage directory.
- Integrate iwe support.
- cmd-] cmd-[ and need to step left/right through kanban columns (ysterday, today, etc.) and should switch highlighting to the top item in the list when doing so
- Items on the kanban must be possible to click and drag between columns
- The first line of the markdown file should be used WITHOUT MARKDOWN FORMATTING as the start of the item. e.g. "# Item One" should show up as "Item One" (no '#')
- Items in the kanban should be able to have sub-items created (and so on, infinitely) using links. The sub-items are not visible directly in the overview. The item should have on the right a down arrow (↪) and a count of subitems (recursive total of all subitems). e.g. '↪5'
- Arrow keys should work to navigate across columns and items (e.g. up/down arrows move up and down the list of items, right and left arrows move to the visually closest item in the next column right or left).
- vi migration keys should work in vi-mode (e.g. hjkl for left, up, down, right)
- When an items is selected, hitting the return key should open it for editing
