- In vi-mode, : commands need to be supported in the editor. The editor should support the full set of vi-editing commands as zed does.
- In the editor when still hovering/attached, cmd-w must NOT close the entire window, it should only close the editor window
- There needs to be an option to re-open the main window with a keyboard shortcut to do so. Opening multiple main windows is supported.
- A selected item should be possible to open in Marked (a markdown visualizer) or MD-Viewer. Which viewer to use should be configurable in the configuration options (navigate to the applicaiton with file dialog).
