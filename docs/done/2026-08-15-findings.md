# Findings in need of being adressed (bugs, improvements, etc.)

## Kanban topics

- Items in the 'Today' column should automatically move into 'Yesterday' on the next day
- cmd-backspace or cmd-del should delete an item.

## Item and Sub-item topics

- Starting a sub-item must be possible from within the editor using
  - right-click on a highlighted word
  - right-cick with no highlighted word - promps for the word/short phrase that will create the link
  - a keyboard shortcut when some text is
  - a keyboard shortcut when no text is highlighted - prompts for the word/short phrase that will create the link
- Its must be possible to follow a link from the editor by clicking it, or with the cursor placed on it with a keyboard shortcut
- From a sub-item, it must be possible to go back to the parent item by clicking it in the 'breadcrumbs' or via keyboard shortcut
- An item that is done should show a green check ✅ in the editor window

## Editor topics

- A new item should open with the first line starting with '# ' for the header.
- The font in the editor must be a fixed width.
- The numbers must be the same size/font as the font used in the editor
- The command-mode cursor must be a solid, blinking box
- The edit mode cursor must be a blinking line
- The cursor must always be visible
